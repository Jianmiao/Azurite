- **规划器：** 计划摘要只覆盖固定策略和准备前事实；实际回执随后生成，避免循环摘要。十二类回执按各自结果、内容摘要、运行编号、所有者和卷身份核对，必须具有单独提供的正向批准及可信预期摘要。四个既有可变文件的修改前副本与权限清单必须指向同一对象和同一描述符；准备占用时间不得早于基线或批准，也不得晚于批准有效期。畸形字段返回明确拒绝，不会在后续关联中抛出未处理异常。
- **准备工具：** 固定到 `F:\AzuriteLabs\Editor-20261108-normal`，只声明准确的新目录、文件和权限差异。先保存修改前证据，再进行一个缓存目录的临时创建许可、新缓存文件 CreateNew、保护恢复、日志准备及有限读写授权。前后使用同一对象身份核验。不会整棵目录解除保护、覆盖未知对象或修改日常安装。实际 Apply 需要新采集并预先批准的对象基线，当前没有生成这份生产批准。
- **运行桥接：** 固定当前账户、capabilities、静音无图形参数与预编译辅助程序。准备占用结束后，运行必须重新取得独占权、核对同一待运行记录、实际身份、文件状态及 AA 未运行，再启动。运行时长独立于准备有效期。结束后核对自有进程清理、输入与配置、回复、日志和共享状态零变化。

一个固定的全局待处理记录阻止在上一轮状态未明时启动其他运行编号；每轮仍保留自己的详细证据。释放独占权与释放对象分别记录：释放已成功但对象释放失败时，不会在失去独占权后重新写入 F 盘标记。失败保留诊断，不接受旧回执换编号，也不将未处理状态清成成功。
