# 1.0.0-candidate.deep-3 本地候选

这份候选供本地体验，不创建 GitHub Release。AA 管理器仍显示 1.0.0；程序集产品版本和启动日志带有 deep-3 标记。

## 实际改动

- 大稿增删：`ReuseUnchangedDialogueRows` 在经过身份验证的 Fix 宿主、事务门成功安装后可启用。AA 原生增删和同步继续运行，只在单次同步的指定线程、父节点和 prefab 范围内复用仍对应同一 Script 的对白行。新增只创建新行，删除只销毁被删行，保留原生文字、名称刷新、选择和最终重排。异常或结构不匹配回退原生。新配置默认 false，本地测试显式开启。
- 旧的文字布局缓存曾多次记录零命中，不能当作已实现加速。本候选体验关闭该实验，独立测试行对象复用收益。
- 大稿渲染观察：面板上限由 256 扩为 4096，注册/变换读取分批进行。周期检查没有变化时不误唤醒页面；多面板尾部也能轮询到；超限后可恢复。几何和裁剪回调立即记录变化，单纯变换轮询仍有批处理延迟。
- 静态编辑预览：当变化观察可靠时，按变化绘制优先于旧的 60 FPS 预览兜底；实际动态内容、滚动、加载、保存和重排仍保护。动画列表中的已完成或已取消对象不再单凭驻留阻止静态判定；预览与 Test 单例分别检查。
- 预览像素成本：`ExperimentalPreviewOwnership` 和 `MatchDisplayResolution` 允许在严格绑定检查后按显示区域创建独立纹理。尺寸与绘制频率分离，滚动不触发反复分配。保持源比例/格式，导出接管前恢复。新增消费者或相机替换不能造成提前释放或错误接管。详见 [预览实验](preview-experiments.md)。
- 独立相机调度和屏外 UIPanel 跳过继续保持实验开关；不直接替换整个 URP 渲染器。
- 额外提供 `Preview.DisableEditorBloom` 可选画质取舍：仅 script 编辑器活动时关闭共享 UI Bloom 的 Enable，退出和导出前恢复。本地候选保持关闭，避免把发光效果改变混入前两项优化对照；它不禁用整个 Renderer Feature。

## 证据与限制

原生 SyncScriptList 会 DestroyChildren 后逐行 AddChild，并在方法内部内联 Init 后调用 Refresh。旧版按已存在行对象缓存因重建丢失对象身份，不能解决这个模式。

源链接调用链测试中，64 行插入后新建 1 个对象、销毁 0 个旧对象、移动 1 次兄弟顺序；删除后新建 0 个对象、销毁 1 个对象、无需逐行移动。测试同时覆盖异常恢复和 120 次连续编辑。它证明减少了指定操作次数，不是实机耗时或 GPU 基准。

初次打开仍需创建原生行，文字 Refresh 和最终重排仍为整表处理。这不是完整的可见行虚拟化，不能承诺所有大稿增删已不卡顿。共享 NGUI 面板使直接逐行禁用/跳过几何容易影响选中与裁剪；未经验证的部分未强行开启。

实机日志显示预览源为 1280×720，显示约 1114×626；计划目标为 1120×630，预览像素约少 23.4%，不等于整页 GPU 下降 23.4%。本轮按用户要求不操作 AA，实际帧时间、渲染效果及收益由后续体验日志确认。

## 本地体验

进入同一 640 行稿件，在相同帧率和窗口尺寸下比较：script 页静止、角色/背景选择、增删一条对白及连续增删。检查文字、选择、顺序、滚动和导出恢复。启动日志应有 `build=deep-3`；行复用日志含尝试/命中/提交次数和最后阻断原因，预览日志含实际目标尺寸。

本地保存 DLL、配置和整个模组目录备份。回退时退出 AA 后还原备份，不要同时启用两份 Azurite。
