# Azurite 1.0.36 / AAVideoExport 0.2.6 本地兼容修复

Azurite 1.0.34 的宿主身份检查拒绝当前 AA 1.0.1，导致帧率映射和 AAVE 协议绑定未激活；设置页出现滚轮控件不能证明这些功能正常。隔离 RenderControlClient 测试绕过了宿主识别，不足以验收运行时兼容。

为当前 AA 1.0.1 的 GameAssembly/metadata 组合建立独立的受限宿主 Profile。仍须通过全部已引用生成 API 的结构检查，不使用 AAVE DLL 哈希或插件版本白名单。未知 AA 宿主仍不启用调度，但公共 v1 协议发现与原生补丁资格分开判断。

当前 AA 1.0.1 启用显示器帧率映射、滚动和静止表面的绘制调度。1.0.36 只修正设置页滚轮控件的真实滑块回调。角色列表延迟初始化和图库 LoadBGAsync 入口限流仍保持关闭，因为当前宿主的原生方法指针映射与旧诊断不一致，尚不足以证明深补丁安全。原 1.0.0-fix 的加载状态机、对白深层优化、预览相机/纹理/Bloom 接管及对白虚拟化不向新宿主自动扩展。

| 阶段 | 所有者与边界 |
|---|---|
| 普通界面 | Azurite 只在已验证的安全表面优化；播放、输入、加载和未知动态受保护。 |
| AAVE 首次 acquire | 先发布 owned，再同步通知 Azurite 恢复 FPS、VSync、绘制间隔和已有相机/纹理租约；回调失败中止。 |
| 面板/准备/捕获/收尾 | AAVE 嵌套持有。Azurite 的 Update 与 LateUpdate 提前退出渲染写入；捕获由 AAVE 设置 renderFrameInterval=1。 |
| 取消/完成/关闭面板 | AAVE 恢复捕获与面板快照；最后一个租约释放后才通知 Azurite 重新观察空闲。仅完成捕获不等于面板已释放。 |
| 恢复失败/未就绪 | 保守阻止新优化；不把失败伪装成已交还。 |

公开 `RenderControlV1` 主版本、属性、托管事件及主线程顺序不变。新的逐帧音频预算和编码参数沿用 AAVE 0.2.5，本次兼容验证不能替代整片音画同步验收。

验证包括宿主拒绝的旧 DLL 重现、生产捕获作用域的绘制间隔失败/修复回归、源代码联动的真实 FPS 控制器与协议交接、实际 DLL 的跨模组协议测试。原生验证夹具位于 `E:\aamod\integration\render-control-v1\NativeHandoffAcceptance`，仅用于测试，不能随正式 Mod 分发；实际报告列明已检查阶段。
